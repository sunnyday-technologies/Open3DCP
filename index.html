Open3DCP is an open schema for 3D-printable concrete mix design and test data. Flat, analysis-oriented, and aligned with ASTM, RILEM, and NIST conventions. A core flat schema plus companion tables, designed so labs can publish data in a common shape. Covers alkali-activated materials, architectural pigments, and standards-aligned material taxonomy.

The Problem

There is not yet a broadly adopted public schema for 3D-printable concrete data. Research papers use inconsistent naming, units, and formats. Combining datasets from different labs often requires painful manual reformatting. Machine learning and meta-analysis on concrete data usually start with substantial data cleaning.

// 02
The Solution

Open3DCP defines a canonical flat schema where every material, process parameter, and test result has exactly one column name, one unit, and one meaning. kg/m³-primary basis (mass-% derivable). Standards-aligned naming. A dataset in this format is easier to inspect, merge, and prepare for analysis.

// 03
3DCP-Native

Unlike conventional concrete databases, Open3DCP has first-class columns for print process parameters (nozzle geometry, layer timing, print speed), fresh-state rheology (yield stress, thixotropy, open time), and interlayer bond properties. Designed around additive-construction reporting needs.

// 04
Schema Only

Open3DCP defines the format, not the data. We publish column names, types, units, and engineering context so that datasets from any lab or research group can be structured in a common format. Adopt the columns relevant to your work and leave the rest null.

Use or contribute to Open3DCP

Open3DCP v1.8 is a public schema draft for recording 3D concrete printing materials, process conditions and test results. It is a data format, not a dataset, prediction service or certification.

Start with the canonical schema and worked examples. The v1.2 manuscript is a preprint, not peer reviewed. Physical validation and professional engineering review remain necessary for real-world use.
